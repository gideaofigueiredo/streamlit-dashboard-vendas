# Dashboard Streamlit

A simple sales dashboard built with Streamlit, displaying data from an API.

## Features

- Fetches and displays sales data in a dataframe.

## Installation

1. Clone the repository.
2. Activate the virtual environment: `.venv\Scripts\activate` (Windows).
3. Install dependencies: `pip install streamlit requests pandas plotly`

## Usage

Run the Streamlit app: `streamlit run dashboard.py`

Alternatively, explore the notebook version: `dashboard.ipynb`

## Requirements

- Python 3.x
- Streamlit
- Requests
- Pandas
- Plotly
